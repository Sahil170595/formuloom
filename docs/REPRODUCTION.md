## Commands

Run from this repository root in an environment containing the dependencies:

```sh
python -B -m formuloom --help
python -B -m formuloom.reproduce --out output/new-run
python -B -m pytest tests -p no:cacheprovider --basetemp=output/test-temp
python -B -m ruff check formuloom tests
python -B -m black --check formuloom tests
python -B -m mypy formuloom --cache-dir output/mypy-cache
```

If using `--basetemp`, create its parent directory first. The checked-in
`tests/conftest.py` forbids HTTPX client sends, including the SDK transport. Tests
use fake provider clients/responses and fresh temporary workbooks, not paid APIs.

## What to Inspect

- `report.json`: schema version, synthetic marker, actual counts and per-sheet
  strict/annotated scores computed from predictions, not stored verdicts.
- `V0.json`, `V8.json`, `V15-mechanical.json`: real diff partitions of the supplied
  candidate cells. Predictions are completed before reference labels are loaded.
- `*-errors.json`: actual FP/FN cell lists, grouped by sheet and row.
- `inspection.json`: row features, dependencies, warnings, weak votes,
  class-conditional LF reliability estimates, probabilities, and EM convergence.
- `routes.json`: actual V15 sheet decisions with explicit arm substitutions in
  the report. This fixture selects the default arm; router unit tests cover the
  other branches and counterexamples.
- `fixture/`: newly generated `init.xlsx`, `complete.xlsx`, `raw_diff.json`,
  `instructions.md`, and `subset.json`. The reference policy is intentionally
  simple, transparent, and synthetic.

The checked-in pair in `examples/synthetic` was generated by `fixtures.py` using
openpyxl. Known formula caches are inserted for this particular fixture using
the retained XML cache patcher. There is no general formula evaluator. Workbook
ZIP timestamps/modified properties need not be byte-identical between generations;
the computation, cell values, and classifications are deterministic.

## Check Scope

Tests cover schema failures, label leakage boundaries, candidate conservation,
formula/reference parsing, row-vs-cell grouping, context splitting, LF conflicts
and abstentions, EM convergence, provider retries and cache behavior, vote ties,
adjudication failure/addition behavior, router boundaries/pruning, cascades,
scout composition, scoring modes, bootstrap/conformal helpers, workbook
perturbation, CLI error paths, and the new end-to-end synthetic reproduction.

Passing these tests establishes local behavior under those fixtures. It does not
establish held-out semantic accuracy, Excel recalculation, production service
readiness, calibrated coverage, or live-provider availability.

Release validation completed with **566 passing tests and no skips**, Ruff
passing, Black check passing, and strict mypy passing across 37 source files.
The synthetic reproduction produced zero provider calls and the counts preserved
in [synthetic-report.json](synthetic-report.json). Packaging/build and live
provider tests remain unperformed.
